## 状态词 / Status vocabulary

`implemented` means source and mapped tests/docs exist. `visual-pending` means the source is present but manual visual sign-off is open. `video-confirmed` means only the recorded observation is confirmed. `implementation-proposal` means an implementation choice is documented without claiming source-video fidelity.
